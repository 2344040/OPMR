Миграция данных

Обнаружен старый формат данных. Система автоматически:

  • Создаст справочник организаций из существующих названий
  • Присвоит каждой команде ID организации и год
  • Команды с протоколами → 2025 год, без протоколов → 2026 год

Ваши данные не будут потеряны. Рекомендуется сделать резервную копию через "Скачать JSON" перед миграцией.
